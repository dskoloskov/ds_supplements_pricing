# Анализ цен на спортпит (Wildberries)

Мой пет-проект, в котором я прошел весь путь от "грязных" данных из API до готовой базы и графиков. Тему выбрал не случайно: я сам занимаюсь в зале и разбираюсь в добавках, поэтому мне было интересно посмотреть на рынок со стороны данных.

## Что проект умеет:
1. **Собирать данные:** Парсер лезет во внутреннее API Wildberries. Обошел защиту, настроил пагинацию и добавил задержки, чтобы не банили.
2. **Чистить мусор:** Обработка в Pandas. Пересчитываю цены из копеек в рубли, вытаскиваю бренды и категории из сложных вложенных JSON.
3. **Хранить по-умному:** Перегнал данные из CSV в нормальную базу SQLite. Сделал две таблицы-справочника (бренды и категории), чтобы всё было по канонам баз данных.
4. **Анализировать:** В Jupyter построил графики, чтобы увидеть, кто из брендов демпингует, а кто продает "премиум".

## Технологии
* **Язык:** Python (Requests, Pandas)
* **База:** SQLite3 (SQL запросы, Foreign Keys)
* **Визуализация:** Seaborn, Matplotlib
* **Среда:** Jupyter Notebook

## Структура файлов
* `src/wb_parser.py` — тот самый парсер.
* `src/process_data.py` — скрипт для очистки данных.
* `src/database_builder.py` — здесь строится база данных.
* `notebooks/01_eda_supplements.ipynb` — ноутбук с графиками и выводами.

## Как запустить
Нужны библиотеки `pandas`, `requests`, `seaborn`, `jupyter`.
Сначала запускаем парсер, потом очистку, потом сборку базы. Все скрипты лежат в `src/`.
